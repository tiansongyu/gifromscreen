# GifFromScreen v0.1.0 — Linux x86_64

首个正式发行版：在 Linux 上录制屏幕、逐帧编辑，并在本地导出 GIF。包含桌面程序和命令行工具。本版不是 ScreenToGif 的完整一比一替代，也不作零缺陷声明。

The first non-preview release of GifFromScreen: local screen recording, frame editing and GIF export on Linux. Includes the desktop application and CLI. This is not a claim of complete ScreenToGif parity or defect-free operation.

## 下载、校验与运行 / Download, verify and run

- [Linux x86_64 portable tar.gz](https://github.com/tiansongyu/gifromscreen/releases/download/v0.1.0/gifromscreen-0.1.0-linux-x86_64.tar.gz)
- [Archive SHA-256 checksum](https://github.com/tiansongyu/gifromscreen/releases/download/v0.1.0/gifromscreen-0.1.0-linux-x86_64.tar.gz.sha256)

下载两个文件到同一目录，然后执行。Download both files into the same directory, then run:

```sh
sha256sum --check gifromscreen-0.1.0-linux-x86_64.tar.gz.sha256
tar -xzf gifromscreen-0.1.0-linux-x86_64.tar.gz
cd gifromscreen-0.1.0-linux-x86_64
sha256sum --check SHA256SUMS
./bin/gif-from-screen
```

命令行入口 / CLI: `./bin/gif-from-screen-cli --help`；运行环境诊断 / runtime diagnostics: `./bin/gif-from-screen-cli doctor`。

便携包无需安装或管理员权限。可选 `./install.sh` 添加用户级桌面入口；安装器需要 Python 3.8+。包未签名，SHA-256 用于检验文件完整性，不能独立证明下载来源的真实性。

No installation or administrator access is required. Optional `./install.sh` adds per-user desktop integration and requires Python 3.8+. The package is unsigned; checksums verify integrity, not authenticity independently of the download source.

构建基线为 Ubuntu 22.04 / glibc 2.35。仍需要系统图形库、适用的驱动及 X11 或 Wayland 桌面；Wayland 录屏需要 PipeWire 和桌面对应的 xdg-desktop-portal 后端。视频导入另需系统 `ffmpeg`、`ffprobe`，普通录屏与 GIF 导出不需要它们。

Build baseline: Ubuntu 22.04 / glibc 2.35. System graphics libraries/drivers and an X11 or Wayland desktop remain required. Wayland capture needs PipeWire and a suitable xdg-desktop-portal backend. System `ffmpeg`/`ffprobe` are optional dependencies for video import, not for ordinary recording or GIF export. See the bundled `README.txt`, `BUILD-INFO.json` and [packaging guide](https://github.com/tiansongyu/gifromscreen/blob/v0.1.0/docs/PACKAGING.md).

## 相比 Preview 3 / Since Preview 3

- **多图形画布 / Multi-object shape canvas.** 新增矩形、圆角矩形、椭圆、三角形和块状箭头的组合绘制、选择、移动、缩放与旋转；可一次应用到所选帧，支持撤销重做。Add, select, move, resize and rotate shape groups, then apply them to selected frames as one undoable edit. [Scope](https://github.com/tiansongyu/gifromscreen/blob/v0.1.0/docs/VECTOR-SHAPE-CANVAS.md)
- **更多中英文界面 / More English and Simplified Chinese controls.** 扩展效果、形状、绘图、图层和工程统计，以及水印、字幕、保存文字组和标题帧的表单、校验与后台结果提示。Expanded advanced-editor, watermark, caption, saved-text and title-frame controls, validation and retained job notices. User text, paths, names and numeric values remain data and are not translated.
- **窄窗口布局 / Narrow-window layout.** 将标签与字段保持成对，改善大字体下的表单；窄编辑器使用单层工具检查区滚动，并优先保留返回与语言按钮。Paired fields and improved enlarged-text layouts; stacked editor pages remove the redundant nested inspector scroll and keep Back/Language actions reachable. [Details](https://github.com/tiansongyu/gifromscreen/blob/v0.1.0/docs/NARROW-EDITOR-LAYOUT.md)
- **修复无操作改色 / Fix idle color changes.** 文字、标题及画板的颜色控件不再因无用户操作的界面重绘而改写已有颜色值。Text/title and board pen/background controls preserve stored colors when the user has not edited them. [Text/title evidence](https://github.com/tiansongyu/gifromscreen/blob/v0.1.0/docs/TEXT-TITLE-LOCALIZATION.md)

## 升级提示 / Upgrading

先保存工程并关闭旧程序。便携运行可直接使用新解压目录；如果使用过用户级安装，按旧包卸载说明移除已登记的应用文件，再从新包运行 `./install.sh`。没有原位自动更新；不要手工删除工程或配置目录。

Save projects and close the previous application first. For portable use, run from the new extracted directory. For per-user installations, use the previous package's documented uninstaller before installing the new one. There is no in-place updater; do not manually delete project or configuration directories.

Preview 版本与本版的内部应用版本都可能显示 `0.1.0`，请以 Release 标签、下载校验值及 `BUILD-INFO.json` 区分构建。Preview builds can also report application version `0.1.0`; identify this release by its tag, checksum and build receipt.

## 已知限制 / Known limitations

- 本版为 Linux x86_64 便携包；不提供正式 AppImage、Flatpak、ARM64 或 macOS 包。This release ships the Linux x86_64 tarball only; no distributable AppImage, Flatpak, ARM64 or macOS package is included.
- 工程格式仍为 schema 8、多图形作者仍为 vector v1。独立 WPF 候选路径的 14 案例精确对照不是默认渲染器的一比一认证；未发布的 schema 9 / vector v2 接线不包含在本版。Projects remain on schema 8 with vector-v1 authoring. The separate 14-case WPF candidate result does not certify the default renderer; unreleased schema-9/vector-v2 integration is excluded.
- 界面语言以英语、简体中文为已提供译文，仍有未迁移界面及工具包文本。29 项语言列表是覆盖目标，不是 29 套完整翻译；未提供的译文明确回退英语。English and Simplified Chinese coverage is expanded, not complete. Other language selections explicitly fall back to English; 29 selectable targets do not mean 29 translated interfaces.
- 首页在窄窗口、150% 应用缩放下可能出现卡片重叠，可暂时恢复 100% 缩放或加宽窗口；本版的窄编辑器修复不代表首页此问题已解决。Home-page cards can overlap in a narrow window at 150% application UI zoom. Use 100% zoom or widen the window as a workaround; the included narrow-editor fix does not resolve this home-page issue.
- Wayland 遵循系统分享授权，无法通用地自动排除控制面板、定位全局透明取景框或强制被遮挡来源刷新。全局快捷键默认关闭，Portal 支持取决于桌面。Global shortcuts are off by default. Wayland sharing, placement, source refresh and shortcuts depend on compositor/portal capabilities; recording controls must be kept out of monitor-capture regions.
- 仅导出 GIF、不录音频；物理摄像头、广泛的 GNOME/KDE、多显示器/混合 DPI、长时间高分辨率录制及部分高级几何/画笔精度尚未全面验收。GIF-only output, no audio recording; physical-camera, broader desktop/DPI/monitor, long-recording and advanced geometry/ink fidelity coverage remains incomplete. Large or complex operations can hit explicit resource limits.

按键/点击采集默认关闭；开启后分享 `.gfsproj` 前请检查敏感输入。Key/click metadata collection is opt-in; review projects for sensitive input before sharing. [功能边界 / Full scope](https://github.com/tiansongyu/gifromscreen/blob/v0.1.0/docs/LINUX-STATUS.md) · [问题反馈 / Issues](https://github.com/tiansongyu/gifromscreen/issues)
