# GifFromScreen 0.1.3

This maintenance release improves X11 recording-frame movement and installation
over an existing per-user package.

- Native input and geometry updates wake their workers immediately. Dragging
  requests VSync-paced UI frames without adding a fixed delay after each frame.
- Ready-mode moves reuse border windows and batch their positions. Recorder
  controls stay still while dragging and move after release. Four corner handles
  support resizing before recording; monitor captures can move within their X11
  root desktop.
- Recording still pauses and verifies the final region before resuming, so
  moving the border does not bypass capture exclusion checks.
- The installer upgrades verified existing packages automatically, retaining a
  rollback copy. It refuses modified managed files and keeps a newer local
  version unless `--allow-downgrade` is explicitly supplied.
- The compatible graphics-backend selection introduced after v0.1.0 is included.

The package targets Linux x86_64, glibc 2.35+, X11 or Wayland, and a compatible
OpenGL ES or Vulkan driver. The drag changes apply to X11. Wayland continues to
use desktop sharing portals. No audio recording is included.

Install or upgrade:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tiansongyu/gifromscreen/releases/latest/download/gifromscreen-installer.sh | sh
```

Save projects and close the previous app before launching the new version.
The installer requires Python 3.8+ and defaults to `~/.local`. Projects and
preferences are retained. [Installation](../PACKAGING.md) ·
[Drag scheduling and verification](../RECORDER-DRAG-CADENCE.md).
