# GifFromScreen 0.1.6

Returning home after recording or editing now restores the launcher's original
size instead of retaining the larger work window.

- Restore the default 520 × 190 home window, or the size you chose on home.
- Reset the larger minimum size left by recorder restoration.
- Wait for pending recording-window restoration before resizing home.
- Preserve window dimensions across repeated sessions and UI zoom changes.
- Wait for an unmaximize acknowledgement before requesting the home size.

Install or upgrade:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tiansongyu/gifromscreen/releases/latest/download/gifromscreen-installer.sh | sh
```

Save projects and close the previous app before launching the update. Linux
x86_64, glibc 2.35+, Python 3.8+ for installation and a working OpenGL ES or
Vulkan driver are required.

Validation: 859 desktop tests pass, including repeated recording-to-home
cycles, manual home sizes, 1×/1.5×/2× UI zoom, delayed restoration and maximized
work windows. Clippy with warnings denied passes. An isolated X11 recording,
stop, editor and back-to-home run restored the measured 520 × 190 home size.
