# GifFromScreen 0.1.4

This release simplifies the desktop interface and removes the UI-frame round
trip from X11 recording-frame movement.

- Start with four tiles: Recorder, Webcam, Board and Editor. Options keeps
  imports, recent projects, language and theme within reach.
- Open the recording frame directly with valid defaults. A thin border and
  compact bottom bar expose FPS, dimensions and recording actions; detailed
  controls remain in Options.
- Edit with tools across the top, a central preview, a right-side inspector in
  wide windows, and a bottom filmstrip/playback bar. Export GIF opens the export
  configuration without immediately writing a file.
- X11 pointer motion updates native border windows directly, even when the UI
  is delayed. Preview permission is limited to ready mode or a verified held
  capture pause, and final geometry must be acknowledged before resume.
- Keep the verified installer upgrade and rollback behavior from 0.1.3.

Install or upgrade:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tiansongyu/gifromscreen/releases/latest/download/gifromscreen-installer.sh | sh
```

Linux x86_64, glibc 2.35+, Python 3.8+ for installation, and a working OpenGL ES
or Vulkan driver are required. Save projects and close the previous app before
launching the new version. Projects and preferences are retained.
