# GifFromScreen 0.1.5

This release fixes text clipping and controls overflowing their pages when the
window is narrow, labels are long, or fonts are enlarged.

- Wrap section titles and reserve space before drawing dropdown controls.
- Keep path editors and Browse buttons within the available width.
- Stack recorder/export form labels above values when two columns do not fit.
- Add vertical scrolling to open/import/create, camera and board pages.
- Keep the recorder setup action visible above its options, and constrain the
  language dialog to the window width.
- Preserve native X11 frame movement and the verified installer upgrade flow.

Install or upgrade:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tiansongyu/gifromscreen/releases/latest/download/gifromscreen-installer.sh | sh
```

Linux x86_64, glibc 2.35+, Python 3.8+ for installation, and a working OpenGL ES
or Vulkan driver are required. Save projects and close the previous app before
launching the updated version. Projects and preferences are retained.

Validation: 855 desktop tests pass. The new rendered-text audit checks English
and Chinese, narrow and wide layouts, enlarged fonts, scrolled content, all
editor tool categories, export, language settings and recorder states. Clippy
with warnings denied passes. Native UI checks use an isolated Xvfb desktop.
